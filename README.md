# VectorOPS

**Live & Recorded Drone Video Intelligence for Mission Operations**

VectorOPS is a Windows application from Adventure Ready Consulting LLC that provides AI-assisted analysis of live and recorded drone video for mission operations.

This repository provides official VectorOPS application releases and installation information.

## Current Release

**VectorOPS 1.0.1**

Download the latest signed installer from the GitHub **Releases** section.

VectorOPS release packages are digitally signed by **Adventure Ready Consulting LLC** using Microsoft Artifact Signing.

No separate ARC certificate installation is required.

## Installation

1. Open the latest VectorOPS release in the **Releases** section of this repository.
2. Download `VectorOPS.Package_1.0.1.0_x64.appxbundle`.
3. Open the downloaded package in Windows.
4. Confirm the publisher is **Adventure Ready Consulting LLC**.
5. Select **Install**.
6. Launch VectorOPS after installation completes.

## Licensing

VectorOPS requires an approved Operations License.

After installation:

1. Launch VectorOPS.
2. Select **Upgrade to Operations License**.
3. Enter your work email address.
4. Verify your email.
5. Your Operations License request will be reviewed by your Account Manager.
6. Once approved, restart VectorOPS.

VectorOPS will display **Operations Approved** when the licensing process is complete.

## System Requirements

VectorOPS is distributed as a signed Windows x64 application package.

A supported Windows system and internet connectivity are required for installation, licensing, and cloud-based AI functionality.
